# FileFlex Converter

A fast, Apple-inspired file conversion web app UX prototype.

## Highlights

- Convert immediately without login.
- Optional login/signup toggle to unlock conversion history.
- Drag-and-drop upload with progress animation.
- Guided flow: Upload -> Convert -> Download.
- Glassmorphism UI with premium transitions.
- Privacy-first messaging (auto-delete after conversion).

## Run locally

```bash
npm install
npm run dev
```

## Supported input formats

PDF, DOCX, JPG, PNG, XLSX, PPTX, TXT

## Supported conversion options

- PDF -> Word
- PDF -> JPG
- PDF -> TXT
- Word -> PDF
- Image -> PDF
- Image -> Word
- Excel -> PDF
- PowerPoint -> PDF
